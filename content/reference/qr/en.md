# QR Codes API

The REST API behind [QR Codes](/products/qr-tracked): create tracked codes and change where they point after they are printed, route scans by rules, read scan analytics, serve codes from your own domain, import codes in bulk, and receive a webhook on every scan. Every operation below shows its request in the language picked at the top of the page. QR Codes has no SDK yet, so TypeScript, Python and Go use each language's usual HTTP client.

Calls take an API key for QR Codes, created in your [account console]({{ACCOUNT_BASE_URL}}/api-keys).
