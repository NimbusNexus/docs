# API QR-кодів

REST API, на якому працюють [QR-коди](/products/qr-tracked): створюйте трекінгові коди й змінюйте, куди вони ведуть, уже після друку, маршрутизуйте сканування за правилами, читайте аналітику сканувань, віддавайте коди з власного домену, імпортуйте коди масово й отримуйте вебхук на кожне сканування. Кожна операція нижче показує свій запит мовою, вибраною вгорі сторінки. Для QR-кодів SDK поки немає, тому для TypeScript, Python і Go використовується звичайний HTTP-клієнт кожної мови.

Для викликів потрібен API-ключ для QR-кодів, створений у [консолі акаунта]({{ACCOUNT_BASE_URL}}/api-keys).
