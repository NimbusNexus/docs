# API de Códigos QR

A API REST por trás do produto [Códigos QR](/products/qr-tracked): crie códigos rastreáveis e mude para onde eles apontam depois de impressos, roteie leituras por regras, consulte a análise de leituras, sirva códigos a partir do seu próprio domínio, importe códigos em lote e receba um webhook a cada leitura. Cada operação abaixo mostra a requisição na linguagem escolhida no topo da página. O produto Códigos QR ainda não tem SDK, então TypeScript, Python e Go usam o cliente HTTP habitual de cada linguagem.

As chamadas usam uma chave de API de Códigos QR, criada no [console da sua conta]({{ACCOUNT_BASE_URL}}/api-keys).
