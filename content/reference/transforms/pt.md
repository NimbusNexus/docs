# API de Transforms

A API REST por trás do [Transforms](/docs/product-transforms): crie pipelines e leia-os; salve e liste as versões deles; teste um documento, execute um pipeline salvo sobre uma requisição e liste os templates para começar; gerencie os slots de credencial; e consulte seu plano e seu uso. Cada operação abaixo mostra a requisição na linguagem escolhida no topo da página. O Transforms ainda não tem SDK, então TypeScript, Python e Go usam o cliente HTTP habitual de cada linguagem.

As chamadas usam uma chave de API de Transforms, criada no [console da sua conta]({{ACCOUNT_BASE_URL}}/api-keys?product=transforms). O [início rápido](/docs/product-transforms/quickstart) guia você pelo primeiro pipeline, e a [referência](/docs/product-transforms/reference) explica os objetos, as funções, os limites de cada plano e os erros.
