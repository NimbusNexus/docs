# API Transforms

L’API REST derrière [Transforms](/docs/product-transforms) : créez des pipelines et lisez-les ; enregistrez et listez leurs versions ; testez un document, exécutez un pipeline enregistré sur une requête et listez les modèles dont un pipeline peut partir ; gérez les emplacements de justificatifs ; et consultez votre plan et votre consommation. Chaque opération ci-dessous montre sa requête dans le langage choisi en haut de la page. Transforms n’a pas encore de SDK : TypeScript, Python et Go utilisent donc le client HTTP habituel de chaque langage.

Les appels demandent une clé API Transforms, créée dans votre [console de compte]({{ACCOUNT_BASE_URL}}/api-keys?product=transforms). Le [démarrage rapide](/docs/product-transforms/quickstart) guide la création d’un premier pipeline, et la [référence](/docs/product-transforms/reference) décrit les objets, les rôles, les limites de chaque plan et les erreurs.
