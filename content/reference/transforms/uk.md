# API Transforms

REST API, на якому працює [Transforms](/docs/product-transforms): створюйте конвеєри й читайте їх; зберігайте й переглядайте їхні версії; тестуйте документ, запускайте збережений конвеєр на запиті й виводьте список шаблонів, з яких можна почати; керуйте слотами облікових даних; перевіряйте свій план і споживання. Кожна операція нижче показує свій запит мовою, вибраною вгорі сторінки. Для Transforms SDK поки немає, тому для TypeScript, Python і Go використовується звичайний HTTP-клієнт кожної мови.

Для викликів потрібен API-ключ для Transforms, створений у [консолі акаунта]({{ACCOUNT_BASE_URL}}/api-keys?product=transforms). [Швидкий старт](/docs/product-transforms/quickstart) проводить через перший конвеєр, а [Довідник](/docs/product-transforms/reference) описує обʼєкти, ролі, ліміти кожного плану й помилки.
