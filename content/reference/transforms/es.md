# API de Transforms

La API REST que hay detrás de [Transforms](/docs/product-transforms): crear pipelines y leerlas; guardar y listar sus versiones; probar un documento, ejecutar una pipeline guardada con una petición y listar las plantillas de las que partir; gestionar los slots de credenciales; y consultar tu plan y tu consumo. Cada operación de abajo muestra su petición en el lenguaje elegido en la parte superior de la página. Transforms todavía no tiene SDK, así que TypeScript, Python y Go usan el cliente HTTP habitual de cada lenguaje.

Las llamadas requieren una clave de API de Transforms, creada en la [consola de tu cuenta]({{ACCOUNT_BASE_URL}}/api-keys?product=transforms). El [inicio rápido](/docs/product-transforms/quickstart) te guía por una primera pipeline, y la [referencia](/docs/product-transforms/reference) explica los objetos, los roles, los límites de cada plan y los errores.
