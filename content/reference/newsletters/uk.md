# API Newsletters

REST API, на якому працює Newsletters: керуйте списками та їхніми темами, публікуйте форми підписки з подвійним підтвердженням, керуйте підписниками та їхніми згодами, пишіть, тестуйте й надсилайте випуски. Кожна операція нижче показує свій запит мовою, вибраною вгорі сторінки. Для Newsletters SDK поки немає, тому для TypeScript, Python і Go використовується звичайний HTTP-клієнт кожної мови.

Для викликів потрібен API-ключ для Newsletters, створений у [консолі акаунта]({{ACCOUNT_BASE_URL}}/api-keys). Публічні маршрути для підписників ключа не потребують: саме їх викликають форма підписки й посилання в надісланих листах.
