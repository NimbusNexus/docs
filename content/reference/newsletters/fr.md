# API Newsletters

L’API REST derrière Newsletters : gérez les listes et leurs thèmes, publiez des formulaires d’inscription en double opt-in, gérez les abonnés et leur consentement, et rédigez, testez et envoyez des numéros. Chaque opération ci-dessous montre sa requête dans le langage choisi en haut de la page. Newsletters n’a pas encore de SDK : TypeScript, Python et Go utilisent donc le client HTTP habituel de chaque langage.

Les appels demandent une clé API Newsletters, créée dans votre [console de compte]({{ACCOUNT_BASE_URL}}/api-keys). Les routes publiques des abonnés ne demandent pas de clé : ce sont elles qu’appellent un formulaire d’inscription et les liens des e-mails envoyés.
