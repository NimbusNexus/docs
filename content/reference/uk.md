# Довідник API

Кожен продукт NimbusNexus — це REST API, і тут перелічено всі операції. Застосунки — це керовані продукти, які ви викликаєте зі свого коду: Webhooks, Inboxes, QR-коди та Request Bins. Інфраструктура — це хмарні ресурси у ваших проєктах: VM, сховище, бази даних, мережа й DNS.

Кожна операція показує свій запит мовою, вибраною вгорі сторінки. REST — це `curl`. Для TypeScript, Python і Go ви бачите виклик SDK, якщо продукт має SDK, а якщо ні — звичайний HTTP-клієнт цієї мови. Автентифікація всюди однакова: API-ключ у заголовку `Authorization`, як налаштовано на сторінці [REST API](/docs/setup/rest). Помилки мають єдиний формат, описаний на сторінці [Помилки](/docs/errors).
