# Довідник API

Кожен продукт NimbusNexus — це REST API, і тут перелічено всі операції. Застосунки — це керовані продукти, які ви викликаєте зі свого коду: Webhooks, Inboxes, QR-коди та Request Bins. Інфраструктура — це хмарні ресурси у ваших проєктах: VM, сховище, мережа й DNS.

Кожна операція показує свій запит мовою, вибраною вгорі сторінки. REST — це `curl`. Для TypeScript, Python і Go ви бачите виклик SDK, якщо продукт має SDK, а якщо ні — звичайний HTTP-клієнт цієї мови. Ви автентифікуєтеся API-ключем: у застосунках — у заголовку `Authorization`, в інфраструктурі — у заголовку `X-API-Key`, як налаштовано на сторінці [REST API](/docs/setup/rest). У застосунках помилки мають єдиний формат, описаний на сторінці [Помилки](/docs/errors); для інфраструктури див. сторінку [Угоди](/docs/conventions#errors).
