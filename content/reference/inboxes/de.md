# Inboxes-API

Die REST-API hinter [Inboxes](/docs/product-inboxes): Wegwerf-E-Mail-Adressen anlegen, die Mail lesen, die bei ihnen ankommt, sowie Tarif und Verbrauch prüfen. Jede Operation unten zeigt ihren Request in der Sprache, die oben auf der Seite gewählt ist. Inboxes hat noch kein SDK, daher verwenden TypeScript, Python und Go den üblichen HTTP-Client der jeweiligen Sprache.

Aufrufe brauchen einen API-Key für Inboxes, den Sie in Ihrer [Kontokonsole]({{ACCOUNT_BASE_URL}}/api-keys) erstellen. Nachrichten über die API zu lesen erfordert einen bezahlten Tarif; der [Schnellstart](/docs/product-inboxes/quickstart) führt durch eine erste Adresse.
