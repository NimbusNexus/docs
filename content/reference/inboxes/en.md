# Inboxes API

The REST API behind [Inboxes](/docs/product-inboxes): allocate disposable addresses, read the mail they receive, and check your plan and usage. Every operation below shows its request in the language picked at the top of the page. Inboxes has no SDK yet, so TypeScript, Python and Go use each language's usual HTTP client.

Calls take an API key for Inboxes, created in your [account console]({{ACCOUNT_BASE_URL}}/api-keys). Reading messages over the API needs a paid plan; the [quickstart](/docs/product-inboxes/quickstart) walks through a first address.
