# API Inboxes

REST API, на якому працює [Inboxes](/docs/product-inboxes): створюйте одноразові поштові адреси, читайте пошту, яку вони отримують, і перевіряйте свій план і споживання. Кожна операція нижче показує свій запит мовою, вибраною вгорі сторінки. Для Inboxes SDK поки немає, тому для TypeScript, Python і Go використовується звичайний HTTP-клієнт кожної мови.

Для викликів потрібен API-ключ для Inboxes, створений у [консолі акаунта]({{ACCOUNT_BASE_URL}}/api-keys). Щоб читати повідомлення через API, потрібен платний план; [Швидкий старт](/docs/product-inboxes/quickstart) проводить через створення першої адреси.
