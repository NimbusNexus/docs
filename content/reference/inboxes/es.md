# API de Inboxes

La API REST que hay detrás de [Inboxes](/docs/product-inboxes): crear direcciones de email desechables, leer el correo que reciben y consultar tu plan y tu consumo. Cada operación de abajo muestra su petición en el lenguaje elegido en la parte superior de la página. Inboxes todavía no tiene SDK, así que TypeScript, Python y Go usan el cliente HTTP habitual de cada lenguaje.

Las llamadas requieren una clave de API de Inboxes, creada en la [consola de tu cuenta]({{ACCOUNT_BASE_URL}}/api-keys). Para leer mensajes por la API hace falta un plan de pago; el [inicio rápido](/docs/product-inboxes/quickstart) te guía por una primera dirección.
