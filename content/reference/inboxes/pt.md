# API de Inboxes

A API REST por trás do [Inboxes](/docs/product-inboxes): crie endereços de e-mail descartáveis, leia as mensagens que eles recebem e consulte seu plano e seu uso. Cada operação abaixo mostra a requisição na linguagem escolhida no topo da página. O Inboxes ainda não tem SDK, então TypeScript, Python e Go usam o cliente HTTP habitual de cada linguagem.

As chamadas usam uma chave de API de Inboxes, criada no [console da sua conta]({{ACCOUNT_BASE_URL}}/api-keys). Ler mensagens pela API exige um plano pago; o [início rápido](/docs/product-inboxes/quickstart) guia você pelo primeiro endereço.
