# API Inboxes

L’API REST derrière [Inboxes](/docs/product-inboxes) : créez des boîtes, les adresses e-mail jetables, et retrouvez-les par adresse ; renommez-les, désactivez-les et supprimez-les ; lisez le courrier qu’elles reçoivent et faites-y des recherches, dans une boîte ou dans toutes à la fois, et videz-les ; et consultez votre plan et votre consommation. Chaque opération ci-dessous montre sa requête dans le langage choisi en haut de la page. Inboxes n’a pas encore de SDK : TypeScript, Python et Go utilisent donc le client HTTP habituel de chaque langage.

Les appels demandent une clé API Inboxes, créée dans votre [console de compte]({{ACCOUNT_BASE_URL}}/api-keys). Lire les messages via l’API nécessite un plan payant ; le [démarrage rapide](/docs/product-inboxes/quickstart) guide la création d’une première boîte, et la [vue d’ensemble](/docs/product-inboxes#search) couvre la recherche de messages et la lecture de leurs headers.
