# API Inboxes

L’API REST derrière [Inboxes](/docs/product-inboxes) : créez des adresses e-mail jetables, lisez le courrier qu’elles reçoivent et consultez votre plan et votre consommation. Chaque opération ci-dessous montre sa requête dans le langage choisi en haut de la page. Inboxes n’a pas encore de SDK : TypeScript, Python et Go utilisent donc le client HTTP habituel de chaque langage.

Les appels demandent une clé API Inboxes, créée dans votre [console de compte]({{ACCOUNT_BASE_URL}}/api-keys). Lire les messages via l’API nécessite un plan payant ; le [démarrage rapide](/docs/product-inboxes/quickstart) guide la création d’une première adresse.
