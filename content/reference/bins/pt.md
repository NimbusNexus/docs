# API de Request Bins

A API REST por trás do [Request Bins](/docs/product-bins): crie bins e encontre-os pela URL; renomeie, desative e exclua bins; leia e busque as requisições que eles registraram, em um bin ou em todos eles, e esvazie-os; e consulte seu plano e seu uso. Cada operação abaixo mostra a requisição na linguagem escolhida no topo da página. O Request Bins ainda não tem SDK, então TypeScript, Python e Go usam o cliente HTTP habitual de cada linguagem.

As chamadas usam uma chave de API de Request Bins, criada no [console da sua conta]({{ACCOUNT_BASE_URL}}/api-keys?product=bins). Ler requisições capturadas com uma chave exige um plano pago; o [início rápido](/docs/product-bins/quickstart) guia você pelo primeiro bin, e a [referência](/docs/product-bins/reference) explica o que a URL de um bin responde, as funções e os limites de cada plano.
