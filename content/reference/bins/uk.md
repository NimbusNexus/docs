# API Request Bins

REST API, на якому працює [Request Bins](/docs/product-bins): створюйте bin-и й знаходьте їх за URL; перейменовуйте, вимикайте й видаляйте їх; читайте записані ними запити й шукайте серед них, в одному bin-і чи в усіх одразу, і очищайте bin-и; перевіряйте свій план і споживання. Кожна операція нижче показує свій запит мовою, вибраною вгорі сторінки. Для Request Bins SDK поки немає, тому для TypeScript, Python і Go використовується звичайний HTTP-клієнт кожної мови.

Для викликів потрібен API-ключ для Request Bins, створений у [консолі акаунта]({{ACCOUNT_BASE_URL}}/api-keys?product=bins). Щоб читати перехоплені запити за допомогою ключа, потрібен платний план; [Швидкий старт](/docs/product-bins/quickstart) проводить через створення першого bin-а, а [Довідник](/docs/product-bins/reference) описує, що відповідає URL bin-а, ролі й ліміти кожного плану.
