# API Request Bins

L’API REST derrière [Request Bins](/docs/product-bins) : créez des bins et retrouvez-les par URL ; renommez-les, désactivez-les et supprimez-les ; transférez ce qu’ils enregistrent vers votre propre serveur, et testez ce transfert ; lisez les requêtes qu’ils ont enregistrées et faites-y des recherches, dans un bin ou dans tous à la fois, regroupez par chemin les requêtes d’un bin, et videz les bins ; et consultez votre plan et votre consommation, avec ce que le crédit a acheté. Chaque opération ci-dessous montre sa requête dans le langage choisi en haut de la page. Request Bins n’a pas encore de SDK : TypeScript, Python et Go utilisent donc le client HTTP habituel de chaque langage.

Les appels demandent une clé API Request Bins, créée dans votre [console de compte]({{ACCOUNT_BASE_URL}}/api-keys?product=bins). Lire les requêtes capturées avec une clé nécessite un plan payant ; le [démarrage rapide](/docs/product-bins/quickstart) guide la création d’un premier bin, et la [référence](/docs/product-bins/reference) décrit ce que répond une URL de bin, les rôles et les limites de chaque plan.
