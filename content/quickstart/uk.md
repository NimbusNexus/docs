# Швидкий старт

Ця інструкція за три виклики API проведе вас від акаунта, з яким ви ввійшли в дашборд, до запущеної віртуальної машини. Усе, що ви тут робите, можна скасувати — видаліть VM, коли закінчите, і витратите щонайбільше кілька центів.

## Перш ніж почати {#prereqs}

Вам знадобляться три речі:

- Акаунт NimbusNexus. Зареєструйтеся на [{{ROOT_DOMAIN}}]({{BASE_URL}}/register) — ви отримаєте стартовий кредит, якого з запасом вистачить на цей швидкий старт.
- Утиліта командного рядка `curl` або будь-який HTTP-клієнт на ваш вибір. Приклади на цій сторінці використовують `curl`; ті самі виклики працюють будь-якою мовою.
- Близько пʼяти хвилин.

Налаштовувати SSH поки не потрібно. Ключ ми створимо в межах другого виклику.

## 1 · Згенеруйте API-ключ {#api-key}

Увійдіть у дашборд і відкрийте **Settings → API keys → New key**. Дайте ключу мітку, яку згодом упізнаєте (напр. `quickstart`), і скопіюйте значення в надійне місце — воно показується лише один раз.

Експортуйте його як змінну середовища, щоб приклади нижче могли на неї посилатися:

```bash
export NIMBUS_KEY="nn_live_xxxxxxxxxxxxxxxx"
```

API-ключі привʼязані до одного проєкту. Поки що вистачить проєкту за замовчуванням, створеного разом із вашим акаунтом; пізніше навантаження можна розподілити між проєктами без ротації ключів.

## 2 · Оберіть регіон {#region}

NimbusNexus працює в чотирьох регіонах:

| Регіон | Код | Статус |
|---|---|---|
| Вірджинія, США | `us-east-1` | Активний |
| Лос-Анджелес, США | `us-west-1` | Активний |
| Франкфурт, Німеччина | `eu-central-1` | Активний |
| Сінгапур | `ap-southeast-1` | Передзапуск |

Оберіть регіон, найближчий до ваших користувачів (або до вашої наявної інфраструктури). Трафік між регіонами всередині NimbusNexus безкоштовний; egress у публічний інтернет — єдина передача даних, за яку виставляють рахунок.

Канонічний список можна будь-коли отримати через API:

```bash
curl {{API_BASE_URL}}/v1/regions \
  -H "Authorization: Bearer $NIMBUS_KEY"
```

## 3 · Створіть першу VM {#first-vm}

Найменша VM, придатна для реальної роботи, — `gp-1-2`: один vCPU, 2 GB RAM, 25 GB SSD. Вона коштує близько цента на годину. Запустіть таку у Вірджинії командою:

```bash
curl -X POST {{API_BASE_URL}}/v1/vms \
  -H "Authorization: Bearer $NIMBUS_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "quickstart",
    "size": "gp-1-2",
    "region": "us-east-1",
    "image": "ubuntu-24.04"
  }'
```

Відповідь містить ідентифікатор VM і її поточний стан. Перші кілька секунд стан буде `provisioning`, потім — `running`:

```json
{
  "id": "vm_01H...",
  "name": "quickstart",
  "size": "gp-1-2",
  "region": "us-east-1",
  "image": "ubuntu-24.04",
  "state": "provisioning",
  "ipv4": null,
  "created_at": "2026-05-19T18:30:00Z"
}
```

Опитуйте VM раз на секунду, доки `state` не стане `running`, а `ipv4` не заповниться, — це займає близько 28 секунд із кешованим образом або 60–90 секунд, якщо образ завантажується вперше.

## Що ви зробили {#summary}

Ви створили API-ключ, обрали регіон і розгорнули справжню віртуальну машину. Той самий патерн із трьох викликів працює для кожного ресурсу в API: `POST`, щоб створити, `GET`, щоб прочитати, `DELETE`, щоб видалити. Автентифікація, коди регіонів та ідентифікатори ресурсів однакові для всіх типів ресурсів — API спроєктовано так, щоб ви вивчили його один раз і застосовували до чого завгодно.

## Наступні кроки {#next-steps}

- Перегляньте **Довідник API**, щоб побачити всі ендпоінти з параметрами, схемами запитів і відповідей та кодами помилок.
- Прочитайте сторінку **Автентифікація**, щоб зрозуміти, як API-ключі працюють разом із привʼязкою до проєктів, токенами з обмеженим строком дії та підписом вебхуків.
- Прочитайте сторінку **Угоди**, щоб дізнатися правила, яких API дотримується всюди, — ідемпотентність, пагінація, формати помилок, тривалі операції.
- Спробуйте **інтерактивний оглядач API** на [{{API_HOST}}/docs/external]({{API_BASE_URL}}/docs/external) — це Swagger UI, підʼєднаний до робочого API; «Try it out» робить справжні виклики у вашому акаунті.

Коли закінчите, видаліть VM, щоб за неї більше не нараховувалася плата:

```bash
curl -X DELETE {{API_BASE_URL}}/v1/vms/vm_01H... \
  -H "Authorization: Bearer $NIMBUS_KEY"
```
