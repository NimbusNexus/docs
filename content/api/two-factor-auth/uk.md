# Двофакторна автентифікація

Двофакторна автентифікація додає другий фактор (код TOTP із застосунку-автентифікатора або ключ доступу WebAuthn) до входу за паролем. Ендпоінти тут охоплюють реєстрацію, перегляд списку пристроїв, видалення пристроїв і завантаження кодів відновлення.

Користувачі дашборду налаштовують 2FA у браузері на сторінці налаштувань акаунта; цей API призначений для автоматизації (розгортання нового користувача-адміністратора, програмна ротація кодів відновлення, примусове ввімкнення 2FA для всієї організації перед аудитом відповідності). Тим, хто викликає API з API-ключем, 2FA не потрібна — ключі самі є фактором «те, що ви маєте»; 2FA захищає шлях входу людей у дашборд.

Наполегливо рекомендуємо: увімкніть 2FA для кожного акаунта людини, що має ролі в продакшн-проєктах. Більшість компрометацій акаунтів спричинені повторним використанням паролів + відсутністю другого фактора.
