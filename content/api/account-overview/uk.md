# Огляд акаунта

«Акаунт» стоїть над усіма робочими просторами, проєктами й ресурсами, якими ви володієте в NimbusNexus. Він містить контакт для білінгу, назву юридичної особи в рахунках, рівень плану (free / starter / production / enterprise), регіони, до яких вас допущено за списком дозволених, і налаштування для всього акаунта. На одну реєстрацію припадає рівно один акаунт.

Більшість цих ендпоінтів доступні лише для читання тим, хто не є власником, а власникам — для читання й запису. Повсякденна робота відбувається на рівні проєкту; виклики на рівні акаунта — це зазвичай операції, які виконують раз на квартал (зміна контакту для білінгу, запит на новий регіон, перехід на вищий рівень плану).
