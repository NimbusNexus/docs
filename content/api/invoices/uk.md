# Рахунки

Рахунки формуються щомісяця, 1-го числа наступного місяця, і охоплюють усе споживання за попередній календарний місяць. Кожен рахунок деталізовано за ресурсами й днями, тож будь-яку позицію можна простежити до конкретних VM / томів / bucket-ів / баз даних.

Цей ендпоінт дає програмний доступ до тих самих даних, які показує дашборд. Сценарії використання: передавання позицій рахунків у вашу власну систему розподілу витрат, архівування рахунків для податкових цілей, звіряння з вашим реєстром замовлень на закупівлю.

Рахунки також доступні в PDF — у тому самому форматі, що використовується для подання податкових відрахувань у більшості юрисдикцій. Канонічне джерело — формат JSON; PDF генерується з JSON.
