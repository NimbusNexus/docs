# Білінг

Білінг ведеться окремо для кожного робочого простору. Ці ендпоінти показують фінансовий стан робочого простору й зберігають його платіжні дані:

- `GET /api/v1/billing/public/balances` — неоплачені нарахування за постоплатою, доступний промокредит і баланс передоплати, усе в одному зрізі.
- `GET /api/v1/billing/public/accrued_charges` — загальна сума нарахувань на цей момент, яку ще не сплачено.
- `GET /api/v1/billing/public/cash_balance` — баланс передоплати й час його останньої зміни.
- `GET /api/v1/billing/public/promotion_grants` — активний промокредит: скільки лишилося від кожного гранту і коли він спливає.
- `GET` і `PATCH /api/v1/billing/public/billing_info` — платіжна адреса, назва компанії та адреси електронної пошти, на які надходять виписки й квитанції.

Самі рахунки через API недоступні.

Ці виклики потребують сесії, у яку ви ввійшли, переданої як `Authorization: Bearer` або як cookie сесії. API-ключем їх викликати не можна.
