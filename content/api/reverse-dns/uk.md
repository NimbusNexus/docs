# Зворотний DNS (записи PTR)

Зворотний DNS — це імʼя хоста, яке отримує той, хто питає: «Яке імʼя стоїть за цим IP?» Це протилежність звичайному DNS-розвʼязанню. Записи містяться в окремому дереві (`in-addr.arpa.` для IPv4, `ip6.arpa.` для IPv6) і є авторитативними для блоку IP, який вони охоплюють.

Для більшості VM достатньо зворотного DNS за замовчуванням (`unused.nimbusnexus.net` або подібного). Налаштуйте власний PTR, коли:

- **Ви запускаєте поштовий сервер.** Більшість великих поштових провайдерів відхиляють листи з IP, чий PTR не збігається з прямим DNS імені хоста відправника. Без відповідного PTR частка доставлених листів падає до нуля.
- **Партнер додав вас до списку дозволених за ідентифікацією на основі PTR.** Деякі фаєрволи для вхідного TCP перевіряють адресу спершу зворотним, а потім прямим DNS-запитом.

Записи PTR можна налаштувати лише для [плаваючих IP](/docs/api/floating-ips), виділених NimbusNexus: для IP, який нам не належить, PTR встановити не можна.
