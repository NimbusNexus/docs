# Дані про ціни

Ендпоінти даних про ціни — це потік лише для читання з цінами NimbusNexus, по одному ендпоінту на кожен вид ресурсу:

- `GET /api/v1/pricing/vm` — розміри VM. `architecture` і `vm_class` обовʼязкові; `cpu` і `ram` звужують список.
- `GET /api/v1/pricing/storage` — блокове сховище, для одного `volume_type`.
- `GET /api/v1/pricing/port`, `/api/v1/pricing/floating_ip` і `/api/v1/pricing/image` — мережеві порти, плаваючі IP і зберігання образів.
- `GET /api/v1/pricing/bandwidth` — вихідний трафік.

Кожна ціна має свій розрахунковий період: одноразово, щогодини, щодня, щомісяця або щороку. Щоб їх прочитати, входити не потрібно. Виклик, привʼязаний до одного з ваших проєктів, отримує ціни, що діють для вашого робочого простору; будь-який інший — ціни з прайс-листа.

Сценарії використання: вбудовування оцінок вартості в реальному часі у ваш процес розгортання (показати «ця VM коштуватиме $X/міс», перш ніж користувач натисне Launch), створення внутрішніх інструментів для розподілу витрат або просто ведення власної таблиці «скільки NimbusNexus бере за X прямо зараз».

Ціни вказано в USD.
