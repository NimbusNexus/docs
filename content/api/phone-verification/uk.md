# Підтвердження телефону

Підтверджений номер телефону може слугувати резервним другим фактором і каналом відновлення в тих рідкісних випадках, коли користувач утратив і пароль, і свій пристрій TOTP/WebAuthn. Підтвердження відбувається за стандартною схемою «ми надсилаємо код у SMS, ви його вводите».

SMS як основний фактор 2FA слабший за TOTP чи WebAuthn (атаки з підміною SIM-картки, вразливості SS7). NimbusNexus підтримує 2FA через SMS, але для нових підключень другого фактора за замовчуванням використовує TOTP; для акаунтів рівня production SMS пропонується лише як шлях відновлення. Акаунти Enterprise можуть повністю вимкнути SMS, якщо їхня модель загроз його виключає.
