# Образи VM

Образ VM — це шаблон ОС, з якого завантажується кореневий диск нової VM. NimbusNexus надає **публічні образи** для основних дистрибутивів Linux і Windows Server; також можна завантажити свої **власні образи**, зібрані за допомогою інструментів на кшталт Packer або створені зі снапшота налаштованої VM.

## Публічні образи {#public-images}

Публічний каталог оновлюється щомісяця патчами безпеки. Slug-и стабільні між патчами: якщо взяти `ubuntu-24.04` сьогодні й ще раз через 6 місяців, ви отримаєте ту саму основу з патчами за 6 місяців. Якщо потрібні побайтово відтворювані завантаження, закріпіть slug з датою (напр., `ubuntu-24.04-20260301`).

Наразі опубліковані slug-и:

- `ubuntu-24.04`, `ubuntu-22.04`, `ubuntu-20.04`
- `debian-12`, `debian-11`
- `fedora-40`, `fedora-39`
- `rocky-9`, `rocky-8`
- `almalinux-9`, `almalinux-8`
- `windows-2022`, `windows-2019`

Кожен публічний образ містить нашу мінімальну конфігурацію cloud-init: SSH-ключі, додані із зареєстрованих ключів проєкту (див. сторінку [SSH-ключі](/docs/api/ssh-keys)), `apt-get update` або аналог під час першого завантаження і сервіс метаданих, закріплений за адресою `169.254.169.254`.

## Власні образи {#custom-images}

Власні образи приймаються як файли **raw**, **qcow2** або **vmdk** розміром до **128 GB** у нестиснутому вигляді. Під час завантаження образ конвертується в наш внутрішній формат (~1–3 хвилини на GB), а потім стає звичайним завантажувальним образом для будь-якої VM у тому самому регіоні.

Зберігання власних образів тарифікується за \$0,013/GB·міс (тариф Standard в обʼєктному сховищі). Окремого рівня «сховище образів» немає.

## Регіони {#regions}

Публічні образи доступні в кожному активному регіоні. Власні образи привʼязані до регіону: образ, завантажений у `us-east-1`, не можна використати для завантаження VM в `eu-central-1` без копіювання. Для реплікації використовуйте `POST /v1/vm-images/{id}/copy` (у довіднику нижче його ще немає — незабаром).
