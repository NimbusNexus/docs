# Запити на регіони

За замовчуванням нові акаунти отримують доступ до одного регіону (того, який обрали під час реєстрації). Щоб отримати доступ до додаткових регіонів, потрібен запит на регіон — коротка форма з описом навантаження, якому потрібен новий регіон. Більшість продакшн-акаунтів схвалюють протягом робочого дня; така перевірка існує для планування потужностей і для виявлення нетипових патернів (зовсім новий акаунт, що в перший же день просить потужності в пʼяти регіонах, вартий короткої розмови).

Цей ендпоінт також обробляє збільшення квот — запит на підвищення ліміту кількості VM, vCPU або сховища в регіоні, до якого ви вже маєте доступ. Причина перевірки та сама: великі запити потребують планування потужностей. Саму модель квот описано на сторінці [Квоти](/docs/api/quotas).

Цей API існує для того, щоб автоматизоване розгортання могло надіслати запит і не чекати на результат; схвалення все одно відбувається вручну на нашому боці (це один із небагатьох куточків API, які навмисно не є повністю самообслуговуванням).
