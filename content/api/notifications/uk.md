# Сповіщення

Налаштування сповіщень визначають, які події запускають лист якому контакту, а які натомість (або додатково) запускають доставку вебхука. Серед категорій — алерти білінгу, події безпеки, попередження про квоти, оголошення про планове обслуговування та релізи функцій.

Значення за замовчуванням розумні: сповіщення про білінг і безпеку завжди надходять контакту для білінгу/безпеки незалежно від налаштувань. Налаштовувати можна операційні категорії: вікна обслуговування, пороги квот, оголошення про бета-функції тощо.

Для більших команд типовий підхід — спрямовувати операційні сповіщення через вебхуки у вашу систему керування інцидентами (PagerDuty, Opsgenie), а не листом одному контакту. Маршрут через вебхуки тут має ту саму семантику доставки, що описана на сторінці [Вебхуки платформи](/docs/webhooks).
