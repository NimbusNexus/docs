# Мережеві порти

Мережевий порт — це точка підключення між мережею й тим, що її використовує: VM, балансувальником навантаження, маршрутизатором. Більшість користувачів не керують портами напряму: вони створюють VM із підключенням до мережі, а порт створюється за лаштунками. Цей API призначений для випадків, коли вам таки потрібен прямий контроль: заздалегідь виділити порт + IP перед запуском VM, підʼєднати балансувальник навантаження до конкретного відомого IP або перенести IP сервісу між хостами.

Порт має MAC-адресу, одну або кілька IP-адрес у батьківській підмережі та, за потреби, [групи безпеки](/docs/api/security-groups), які фільтрують вхідний і вихідний трафік. Порти зберігають стан: якщо видалити VM, до якої був підʼєднаний порт, він залишається й готовий до підʼєднання до VM, що її замінить.
