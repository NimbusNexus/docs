# Мережеві порти

Мережевий порт — це точка підключення між мережею й тим, що її використовує: VM, балансувальником навантаження, маршрутизатором. Більшість користувачів не керують портами напряму: вони створюють VM із підключенням до мережі, а порт створюється за лаштунками. Цей API призначений для випадків, коли вам таки потрібен прямий контроль: створити порт із відомим IP і підʼєднати його до запущеної VM, підʼєднати балансувальник навантаження до конкретного відомого IP або перенести IP сервісу між хостами.

Порт має MAC-адресу, одну або кілька IP-адрес у батьківській підмережі та, за потреби, [групи безпеки](/docs/api/security-groups), які фільтрують вхідний і вихідний трафік. Порт, який ви створили самі, переживає VM, до якої підʼєднаний, і готовий до підʼєднання до VM, що її замінить; порти, які VM отримує під час створення в мережі, видаляються разом із нею. Порт у зовнішній мережі тарифікується, доки ви його не видалите (див. [Дані про ціни](/docs/api/pricing-data)).

Під час створення VM можна вказати лише мережі (`network`), тож створений вами порт підʼєднується до VM після запуску: `POST /api/v1/instance/{server_id}/interfaces/` з його `port_id`.
