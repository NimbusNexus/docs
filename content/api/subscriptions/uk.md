# Підписки

Ваша підписка — це рівень плану + розрахунковий період + налаштування оплати, які визначають усе, за що нараховується плата в акаунті. Рівні плану (free, starter, production, enterprise) визначають SLA підтримки, квоти за замовчуванням, включений кредит і доступ до певних регіонів. Розрахунковий період (місячний, річний) задає частоту рахунків; річна оплата дає знижку порівняно з місячною.

Перехід на вищий план набирає чинності одразу; перехід на нижчий — наприкінці поточного розрахункового періоду, щоб уникнути суперечок щодо пропорційного перерахунку посеред місяця. Плани Enterprise узгоджуються й налаштовуються вручну; API підтримує плани до production включно, а запити на enterprise передає контакту з відділу продажів.
