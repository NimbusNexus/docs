# Інтерфейси VM

Інтерфейс VM — це мережеве підключення VM: привʼязка між VM та одним із її [мережевих портів](/docs/api/network-ports). Більшості VM достатньо інтерфейсу за замовчуванням, створеного під час запуску; керувати інтерфейсами напряму потрібно лише тоді, коли VM треба підʼєднати до кількох мереж (напр., для сервісів із підключенням до двох мереж або для перемикання мереж у схемі blue/green).

Підʼєднання інтерфейсу відбувається «на гарячу» — VM не перезавантажується. Ядро одразу бачить новий NIC; можливо, вам доведеться ввімкнути його (`ip link set <name> up`) і налаштувати адресацію вручну, якщо цього не робить cloud-init образу.

Відʼєднання теж відбувається «на гарячу». Сокети, привʼязані до відʼєднаного інтерфейсу, обриваються; сокети на інших інтерфейсах не зачіпаються.
