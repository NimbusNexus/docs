# Маршрутизатори

Маршрутизатор — це те, що дає **мережі тенанта** (і її підмережам) доступ до інтернету. VM, підʼєднані до підмережі тенанта, не можуть самі вийти в публічний інтернет — вони перебувають у приватному сегменті L2. Маршрутизатор зʼєднує цей сегмент із зовнішньою мережею регіону, виконує NAT для вихідного трафіку й (за потреби) обслуговує плаваючі IP для вхідного.

## Коли потрібен маршрутизатор {#when-needed}

- **Публічні VM у мережі тенанта.** Підʼєднайте маршрутизатор, потім виділіть + підʼєднайте [плаваючий IP](/docs/api/floating-ips). Вихідний трафік проходить NAT через маршрутизатор; вхідний на плаваючий IP маршрутизується назад до VM.
- **Змішані приватні/публічні рівні застосунку.** Вебрівень стоїть за маршрутизатором із плаваючим IP; рівні застосунку + БД залишаються приватними й виходять в інтернет (напр., для оновлення пакетів) через source-NAT маршрутизатора.
- **Маршрутизація між кількома підмережами.** Маршрутизатор може одночасно обслуговувати кілька підмереж. Трафік між двома підмережами на одному маршрутизаторі залишається всередині VPC, ніколи не виходить за межі NimbusNexus і не тарифікується як egress.

Якщо ви підʼєднуєте VM безпосередньо до зовнішньої мережі, маршрутизатор не потрібен — зовнішня мережа САМА Є шлюзом.

## SNAT, DNAT і плаваючі IP {#nat}

Маршрутизатор має одне підключення до зовнішнього шлюзу (до зовнішньої мережі регіону) і нуль або більше внутрішніх підключень (до підмереж тенанта).

- **Вихідний трафік із приватної VM** → маршрутизатор виконує source-NAT на свій зовнішній IP. Кілька приватних VM спільно використовують цей один зовнішній IP для вихідного трафіку.
- **Вхідний трафік на плаваючий IP** → маршрутизатор виконує destination-NAT на приватну VM, до якої підʼєднано плаваючий IP. Приватна VM бачить початковий IP джерела (для вхідного трафіку ми зберігаємо IP клієнта під час NAT; SNAT застосовується лише до вихідного).

NAT не налаштовують напряму: маршрутизатор робить це сам, залежно від того, які підмережі підʼєднано й які плаваючі IP ви створили.

## Статичні маршрути {#static-routes}

Маршрутизатор має таблицю статичних маршрутів, яку можна заповнити для призначень, відмінних від маршруту за замовчуванням, — напр., щоб трафік однієї підмережі до конкретного CIDR ішов через іншу VM (VPN-пристрій, прозорий проксі). Більшість користувачів ніколи цього не торкаються; ця можливість існує для складних схем VPC, яким вона потрібна.
