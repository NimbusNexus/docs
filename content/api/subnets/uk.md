# Підмережі

Підмережа — це блок IP-адрес усередині [мережі](/docs/api/networks). VM і балансувальники навантаження підʼєднуються до підмереж, а не безпосередньо до мереж: мережа — це лише контейнер, у якому містяться одна або кілька підмереж.

## Розмір CIDR {#cidr}

CIDR вибирають під час створення. Типові розміри:

| Сценарій | CIDR | Доступні адреси |
| --- | --- | --- |
| Тестування з однією VM | `/29` | 5 |
| Невеликий застосунок (≤ 20 VM) | `/27` | 27 |
| Середній застосунок (≤ 100 VM) | `/25` | 123 |
| Великий застосунок | `/24` | 251 |
| VPC на весь проєкт | `/16` | 65 531 |

Кожна підмережа резервує: адресу мережі (першу), широкомовну адресу (останню), шлюз (зазвичай `.1`) і наш DHCP-сервер (зазвичай `.2`). Тож підмережа `/24` має 256 адрес загалом, але для VM доступна лише 251.

Підмережу можна **збільшити** (`/27` → `/25`) наживо, без переривання роботи. Зменшити підмережу, не створивши її заново, **не можна**: наявним VM довелося б змінити IP-адреси.

## DHCP, SLAAC і поведінка шлюзу {#dhcp}

- **Підмережі IPv4** за замовчуванням використовують DHCP. Кожна VM отримує фіксовану адресу з доступного діапазону підмережі. Якщо потрібна стабільна адреса (напр., для бекенда LB у DNS), конкретні IP можна заздалегідь виділити через ендпоінт портів.
- **Підмережі IPv6** за замовчуванням використовують SLAAC. Кожна VM автоматично генерує адресу з префікса `/64` підмережі + своєї MAC-адреси. Для середовищ, яким потрібна детермінована адресація, DHCPv6 можна ввімкнути за бажанням.
- **Шлюз** задається для кожної підмережі. Для підмереж тенанта, яким потрібен доступ до інтернету, шлюз вказує на [маршрутизатор](/docs/api/routers), підʼєднаний до підмережі; для автоматично створеної підмережі зовнішньої мережі шлюз вказує на наш edge-рівень.

## Кілька підмереж в одній мережі {#multiple}

До однієї мережі можна підʼєднати кілька підмереж. VM, підключена до цієї мережі, може бути доступною з кожної підмережі всередині неї (з урахуванням груп безпеки). Це корисно для подвійного стека IPv4 + IPv6: одна підмережа v4 + одна підмережа v6 в одній мережі дають кожній VM обидва стеки.
